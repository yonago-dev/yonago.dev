# 米子で集まりに使える場所

yonago.devの集まりに使えそうな場所の一覧です。2026年11月16日に、それぞれのページで見た内容をまとめました。

- 料金や条件は変わります。使う前に、リンク先か電話で確かめてください
- 空いているかどうかは、どこも確かめていません
- 抜けている所や、古くなった所を見つけたら、プルリクエストかIssueで教えてください

## 米子駅の近くの、公共の施設

- **[米子市文化ホール](https://www.yonagobunka.net/culturehall/shisetsu/kenshu/)　研修室1・研修室2**
  - 場所：末広町293
  - 広さ：研修室1は51㎡で約36席、研修室2は49㎡
  - 料金（営利目的でなく、入場料を取らない場合）：平日の13〜17時は1,100円と990円。土日祝の13〜17時は1,320円と1,210円。18〜22時は、平日が1,320円と1,210円、土日祝が1,540円と1,430円。冷暖房は別料金（[料金表](https://yonagobunka.net/culturehall/ryoukin/kenshu/)）
  - 設備：机12、椅子36、ホワイトボード。研修室1には40インチの画面（別料金）
- **[米子コンベンションセンター（ビッグシップ）](https://www.bigship.or.jp/bigship/organizer/6/4/)　会議室**
  - 場所：末広町294。米子駅から歩いて約5分
  - 広さ：いちばん小さい第1会議室が56㎡で45席。円卓の第8会議室は24席
  - 料金（冷暖房込み）：第1会議室は、午前2,860円、午後（13〜17時）3,810円、夜間（18〜22時）3,810円。部屋を分けて27席で使うと、午後2,840円（分けて使う予約は、1か月前から）。第8会議室は午後9,050円（[料金表](https://www.bigship.or.jp/bigship/organizer/13/)）
  - 設備：プロジェクター（HDMI）、会議室用のWi-Fi、ホワイトボード1台
  - 予約：6か月前から。[オンライン](https://reserve.bigship.or.jp/)か、窓口・電話
- **[米子市公会堂](https://www.yonagobunka.net/publichall/riyou/)　集会室・和室**
  - 場所：角盤町2丁目61
  - 広さ：集会室1・2・3・5・6は56㎡で36席。集会室4は28㎡で12席。集会室7は43㎡で27席。和室は24畳
  - 料金（いちばん安い区分）：集会室1などは、平日の13〜17時が660円、土日祝が770円。集会室4は330円と380円。冷房は550円、暖房は330円が別にかかる（集会室4は270円と160円）（[料金表](https://www.yonagobunka.net/publichall/ryoukin/shukai/)）
  - 時間：9〜22時
  - 予約：使う月の1年前の月の初日から。電話は0859-22-3236
- **[米子市立図書館](https://www.yonago-toshokan.jp/guide/tamokuteki)　多目的研修室・研修室**
  - 場所：中町8
  - 2階に多目的研修室と研修室があります。行事が無い日は、自習用に開放されています
  - 団体が借りられるかどうかは、ページに書かれていませんでした。電話は0859-22-2612

## 少し離れた、公共の施設

- **[米子市福祉保健総合センター（ふれあいの里）](https://www.city.yonago.lg.jp/13077.htm)　会議室・研修室**
  - 場所：錦町1丁目139-3
  - 広さと料金（福祉や保健が目的でない場合、1時間あたり）：研修室2は20人で380円、中会議室3は40人で520円、研修室1は28人で530円。冷房の期間と暖房の期間は、4〜5割ほど高くなる
  - 時間：9〜21時。水曜は休み
  - 予約：使う日の5か月前から。料金は前払い
  - 料金は2019年10月に載った内容です
- **[米子市男女共同参画センター「かぷりあ」](https://www.city.yonago.lg.jp/9445.htm)　会議室**
  - 使うには、センターの利用団体としての登録が要ります。営利目的の団体、政治や宗教の活動をする団体は登録できません
  - 時間：9〜21時。水曜は休み
  - 予約：使う日の3か月前から。電話は0859-31-1591
  - 部屋の広さと料金は、ページに書かれていませんでした
- **[米子市観光センター](https://www.kaike-onsen.jp/room)（皆生温泉）　研修室・和室・多目的ホール**
  - 場所：皆生温泉3丁目1-1。駐車場は約30台
  - 広さと料金（1時間あたり。18時以降は少し高い）：和室は12.5畳で200円、研修室は84㎡で410円、多目的ホールの半面は133㎡で860円。冷暖房は別料金
  - 設備：2階の会議室で無料のWi-Fi。プロジェクターとスクリーンは1日1,000円。ホワイトボードは無料
  - 予約：電話（0859-35-0175）か予約フォーム。1時間単位
- **[公民館](https://www.city.yonago.lg.jp/33754.htm)（市内に29館）**
  - 料金（1室、1時間あたり）：30㎡未満は、午前330円、正午以降660円。30㎡以上100㎡未満は、660円と1,320円。100㎡以上は、1,320円と2,640円
  - 時間：9〜22時
  - 営利目的、政治や宗教の活動には使えません
  - 予約：使いたい公民館に電話して仮予約→市役所の地域振興課に申請書を出す（電子申請もできる）
  - [公民館の一覧](https://www.city.yonago.lg.jp/item/31443.htm)

## 団体の施設

- **[米子商工会議所](https://www.yonago.net/rental/rental-conference-room)　貸会議室**
  - 場所：加茂町2-204
  - 広さと料金（会員でない場合、平日の13〜17時）：第3会議室は39㎡で5,700円、大会議室Cは54㎡で7,900円
  - 土日祝は、午後で10,000円の追加料金がかかります。小さい部屋は、土日祝に単独では借りられません
  - 17時以降は、1時間ごとに3割増しで、21時まで
  - 原則として、事業所・団体・教育機関などへの貸し出しです
  - 設備：Wi-Fi、ホワイトボード。プロジェクターは8,800円

## コワーキングスペース、レンタルスペース

- **[HARI](https://hari-yonago.com/)**
  - 場所：法勝寺町65
  - 料金：貸切は1時間1,650円（3時間以上から）、1日9,900円。コワーキングは1時間550円、1日2,200円
  - 広さ：6人掛けのテーブル3台、椅子18脚、小上がり（約6畳）
  - 設備：Wi-Fi、電源、ミニキッチン。飲食の持ち込み可。プロジェクターは100円
  - 時間：9〜19時（時間外は相談）。休みは不定
  - 予約：事前の予約が必要。LINE、メール、電話（090-3639-4021）
- **[work space 475](https://www.team-yonago.jp/store/221)**
  - 場所：目久美町97-3。米子駅の南口から歩いて5分
  - 料金：1人で使うと1時間550円。何人かで使うと1時間880円
  - 広さ：コワーキングスペースは39㎡。ミーティングスペースは13㎡で6人まで
  - 時間：9〜21時。無休
  - 講座やイベントにも使える、と書かれています（[予約のページ](https://www.instabase.jp/space/5157198846)）
- **[わだや小路](https://wadaya-akiya.jimdofree.com/)**
  - 場所：糀町1-10。米子駅から歩いて10分
  - 料金：カフェスペース（洋室を含む）は3時間で2,500円。和室は3時間で1,000円。冷暖房込み
  - 予約：オンラインで、2か月先まで。電話は0859-22-2703
- **[U-SPACE米子店](https://www.instabase.jp/tottori-w31202-rentalspace)**
  - 場所：河崎口駅から車で7分
  - 広さと料金（1時間あたり）：Meetingは25㎡で8人まで、1,833〜2,500円。Communityは49㎡で16人まで、2,834〜3,500円
  - 設備：Wi-Fi、プロジェクター。飲食の持ち込み可
- **[ワークボックスふくろう](https://workspace-japan.com/tottori-yonago/)**
  - 米子駅から歩いて15分。1時間110円から、と掲載されています。くわしい内容は確かめていません
