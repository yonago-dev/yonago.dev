// about

yonago.devとは

yonago.devは、鳥取県米子市のエンジニアコミュニティです。米子やその近くで働くエンジニアが、月に1回、顔を合わせて話します。

勉強会というより、同じ町にいる作り手どうしが知り合う場です。使っている言語も、会社員かフリーランスかも、関係ありません。

// why

なぜ始めるのか

米子・山陰にも、おもしろいものを作っている人はたくさんいます。でも、知り合うきっかけがあまりありません。

月に1回顔を合わせて話せる場所があれば、それぞれの仕事も、もう少し楽しくなるはずです。

// what

やること

月に1回の企画

集まって、話したり作ったりします。毎回ちがう企画をやります。

ときどき、もくもく会

それぞれの作業を持ってきて、同じ場所で黙々と進める日です。

企画の例

  • 5分で話す会（LT）
  • カンファレンスの動画を一緒に見る会
  • 1日で小さく作る会
  • AIの使い方を見せ合う会
  • リモートの働き方を見せ合う会

// values

大事にしたいこと

  • 人数を追わない3人でもやります。同じ顔に何度も会えることを大事にします。
  • 準備をがんばらないスライドなしで話せる会にします。続けられる形を選びます。
  • 初めての人を置いていかない内輪の話だけで終わらせません。

// who

こんな人に

  • 米子や近くで働くエンジニア、デザイナー
  • リモートワークで、地元に話せる相手がほしい人
  • エンジニアを目指している学生
  • 境港・安来・松江など、近くの町の人
